# Project Sentinel: landing page

Live at **https://abedalrahmantech.github.io/project-sentinel/**

Sentinel finds the security holes in your code, explains them, fixes them, and proves the fix. This repository holds only the public landing page. The code lives in the team's private repository.

- `index.html`: the whole page, no build step. Edit it and push to `main`; GitHub Pages redeploys in about a minute.
- `assets/`: logo mark and the social preview image used by link previews.
- `docs/PRODUCT.md`, `docs/DESIGN.md`: who the page is for and the visual system (colours, type, spacing). Read these before changing the design.
